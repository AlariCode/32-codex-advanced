# Шаблон PR

Заполни разделы фактами. В проверках указывай команды, рабочий каталог при необходимости, сценарии и результаты. Покажи покрытие каждого критерия готовности. Для раздела без содержимого пиши «Нет» или «Не применимо» с краткой причиной.

```markdown
## Что сделано

- <Изменение и получившееся поведение>

## Как проверено

- `<команда>` — <результат; покрываемые критерии готовности>
- <Сценарий> — <ожидаемый и фактический результат; критерий готовности>

## Скриншоты

<Если менялся фронтенд: изображения или доступные ссылки с подписями страницы и состояния. Иначе: «Не применимо: фронтенд не менялся».>

## Что осталось за рамками

- <Исключения из объема, ограничения и необязательные проверки, которые не выполнены, либо «Нет»>

Closes #<номер>
```
