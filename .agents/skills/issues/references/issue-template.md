# Шаблон задачи

Заголовок issue: краткий проверяемый результат. Заполни текст ниже конкретными данными задачи, заменив все подсказки в фигурных скобках.

```markdown
## Контекст

- PRD: [название]({ссылка на PRD})
- План: [название]({ссылка на план})
- Фаза: {номер} — {название фазы}

{Какую часть результата фазы обеспечивает эта задача и на какое существующее поведение опирается.}

## Что сделать

{Ожидаемый результат: какое поведение или возможность появится после выполнения задачи.}

## Критерии готовности

- [ ] {Наблюдаемый результат основного сценария.}
- [ ] {Проверяемое поведение на значимой границе или при ошибке, если применимо.}
- [ ] {Проверки, подтверждающие результат задачи.}

## Проверка

- Команда: `{команда}` из `{рабочий каталог}` — {что проверяет и ожидаемый результат}.
- Сценарий: {исходные условия, действие и наблюдаемый ожидаемый результат}.

## Зависимости

{Зависит от #123 — название задачи; по одной строке на зависимость. Если зависимостей нет, напиши «нет».}

## Вне задачи

- {Конкретный смежный результат, который не входит в эту задачу; последующая фаза, если известна.}
```
