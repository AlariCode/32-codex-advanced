# Ralph SDK: одна задача

Отдельный пакет, не использует и не изменяет `tools/ralph`.
Требуются Node.js 22+, Git, авторизованный `gh`, доступ к Codex
(`codex login` или `OPENAI_API_KEY`) и окружение проекта для `make check`.
Используется официальный пакет [`@openai/codex-sdk`](https://developers.openai.com/codex/sdk/).

```sh
cd tools/ralph-sdk
npm ci
npm run once -- 42
```

Из корня репозитория: `npm run once --prefix tools/ralph-sdk -- 42`.
Номер обязателен. Скрипт определяет корень через `git rev-parse --show-toplevel`,
получает заголовок и описание через `gh issue view --json`, создаёт `startThread`
с рабочим каталогом корня, `workspace-write` и `approvalPolicy: never`.
Используются модель и авторизация из настроек Codex.

Первый ход передаёт текст задачи в `runStreamed`. Команды показываются одной
короткой строкой и кодом выхода; промежуточные обновления и полный stdout
команд не печатаются. После успешного завершения хода раннер сам запускает
`make check`. При сбое передаёт последние 120 строк (до 24000 символов)
в тот же thread. Максимум два хода исправления: всего до трёх ходов агента
и трёх проверок. Агенту явно указано не запускать `make check` самостоятельно.
Ошибка SDK или оборванный поток останавливают запуск.

Каждый запуск сохраняет отдельный каталог `tmp/ralph-sdk/issue-42-*/`:

- `thread.json` — номер и URL задачи, корень и `thread_id`; записывается
  сразу по `thread.started`, до завершения первого хода;
- `check-0.log`, `check-1.log`, `check-2.log` — полный вывод выполненных проверок;
- `result.json` — результат завершённого цикла и последний ответ агента.

`thread_id` можно использовать в `codex.resumeThread(id, { workingDirectory: root,
sandboxMode: "workspace-write", approvalPolicy: "never" })` или `codex resume <thread_id>`.
Автоматическое восстановление в `once` пока не реализовано: каждый запуск
создаёт новый thread. История сессии хранится самим Codex; `thread.json`
содержит ссылку на неё.

В консоли выводятся номер задачи, результат проверки, число исправлений,
время, thread ID и каталог артефактов. Код выхода — 0 при зелёном `make check`,
1 при ошибке или исчерпании исправлений. Изменения остаются в текущей рабочей
копии; скрипт не создаёт веток, коммитов, PR и не закрывает issue.

Проверки пакета (без обращения к GitHub и модели):

```sh
npm test
npm run typecheck
```
