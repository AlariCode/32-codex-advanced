# Общие правила работы с проектом

Эти правила действуют для всего репозитория. Инструкции во вложенных `AGENTS.md` дополняют их для соответствующих каталогов.

## Правила по областям

- При работе с `backend/` читать и соблюдать [backend/AGENTS.md](backend/AGENTS.md).
- При работе с `web/` читать и соблюдать [web/AGENTS.md](web/AGENTS.md).
- Если задача затрагивает обе области, применять оба набора правил.

## Работа с изменениями

- Перед изменениями изучить существующий код и относящуюся к задаче документацию. Общая структура, запуск и команды проекта описаны в [README.md](README.md).
- Сохранять изменения пользователя и ограничивать правки задачей.
- При изменении поведения актуализировать связанную документацию и проверки.
- Не коммитить секреты, локальные настройки и временные артефакты. Временные результаты проверок хранить в `tmp/`.

## Проверка результата

- Выполнять проверки, соответствующие затронутой области; команды приведены во вложенных инструкциях. Все команды в этих файлах указаны относительно корня репозитория, если явно не сказано иначе.
- Для общей проверки проекта использовать `make check`, для полной сборки — `make build`.
- В итоговом сообщении кратко описать изменения и результаты проверок. Если проверка недоступна, указать причину и что осталось непроверенным; не считать её выполненной.
