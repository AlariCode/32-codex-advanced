# Миграции

Здесь будут версионируемые миграции общей базы API и Worker.
Таблицы ссылок и embeddings пока не создаются: модель данных и размерность
векторов будут определены при реализации функций приложения.

Расширение `vector` включается отдельно в `infra/postgres/init/001-vector.sql`
при первом запуске PostgreSQL с пустым volume.
