# Миграции

Здесь находятся версионируемые миграции общей базы API и Worker.
`001-create-users.sql` задаёт таблицу пользователей для контракта регистрации.
Go-модуль `linkbook/migrations` встраивает SQL-файлы в бинарник API через `go:embed`.
API применяет миграции до запуска HTTP-сервера; интеграционные тесты используют
тот же код в изолированных схемах PostgreSQL.

Файлы выполняются в порядке имён в общей транзакции. Блокировка PostgreSQL
защищает от одновременного применения несколькими экземплярами API.
Таблица `schema_migrations` хранит имя, SHA-256 и время применения.
Повторный запуск пропускает уже применённые миграции, сохраняя пользователей.
При ошибке SQL весь пакет новых миграций откатывается и API не запускается.

Применённые файлы нельзя изменять, удалять или добавлять новую миграцию перед
последней применённой: проверки истории остановят запуск. Для изменения схемы
нужно добавить следующий SQL-файл с большим номером, например `002-...sql`.
Таблицы ссылок и embeddings пока не создаются: модель данных и размерность
векторов будут определены при реализации функций приложения.

Расширение `vector` включается отдельно в `infra/postgres/init/001-vector.sql`
при первом запуске PostgreSQL с пустым volume.
