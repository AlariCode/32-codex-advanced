## #8 — Сохранить форматирование статьи (2026-10-19)

Сделано: введён документ v2 с ограниченным рекурсивным деревом; сохранены
семантические уровни заголовков, strong/em/inline code, безопасные HTTP(S)-ссылки,
вложенные списки/цитаты, таблицы и details/summary. Версия 1 продолжает читаться
прежним decoder/renderer. Worker публикует фактическую версию документа, API
сверяет её с snapshot. Неизвестные поля/типы/версии и trailing JSON отклоняются,
HTML fallback отсутствует. React создаёт только разрешённые теги и явные props;
внешние ссылки имеют noopener noreferrer. Код сохраняет точные пробелы и язык
для существующей подсветки. Код и таблицы имеют отдельную доступную с клавиатуры
прокрутку. Добавлены собственный formatting fixture, Go-регрессии и браузерные
сценарии с настоящими API/worker и отключением источника на 375/768/1440.
OpenAPI JSON/YAML/Go и встроенная HTML-схема дополнены children/href локально.
Карта критериев и сценарии: docs/verification/issue-8.md.

Узнал: Readeck самостоятельно меняет h1 в h2, удаляет короткие таблицы и
теряет details/summary. Принято сохранять их через случайные текстовые маркеры
до отбора статьи и восстанавливать только выбранные фрагменты на прежнем месте
один раз. Class/id используются исключительно как подсказки отбора Readeck,
в архив не попадают. Потерянный защищённый фрагмент вызывает предупреждение.
Строчный code тоже требовал отдельного сохранения whitespace: дополнительный
RED-тест обнаружил схлопывание, исправление прошло точное сравнение строк.

Допущения: v1 не мигрируем; обновлённый allowlist имеет глубину до 64,
до 10000 узлов и до 3 MiB текста/URL. Произвольные атрибуты отбрасываются;
rowspan/colspan/start и известные неподдерживаемые элементы не переносятся,
их наличие отмечается предупреждением вместо заявления о полном результате.
Изображения остаются вне объёма задачи. Генератор OpenAPI с загрузками
не запускался при запрете сети, схема синхронизирована локальными правками.

TDD: исходные новые серверные тесты и fixture добавлены до серверных изменений;
первый make check подтвердил RED из-за отсутствующей версии/структуры.
Assertions после реализации не ослаблялись. Финальный make check завершился
с кодом 0: Go unit tests, vet, frontend lint и typecheck прошли. Отдельный
sandbox-запуск существующего safehttp httptest был ограничен запретом bind;
повтор make check с разрешением локальных портов прошёл. Несовместимый с
ES2017 флаг s в новом браузерном assertion заменён без изменения проверки.

Следующей итерации: предыдущие визуальные проверки приняты по прямому
указанию пользователя; новые браузерные проверки, UX-проход, Playwright и
видео в этой итерации не запускались. make test, make build и make openapi
также не запускались по ограничениям; их и новые e2e выполняет внешний
скрипт. Новых видео нет. Не считать написанные e2e выполненными. Изменения
оставлены в рабочей копии без коммита; инструменты Ralph и .ralph/ не менялись.
