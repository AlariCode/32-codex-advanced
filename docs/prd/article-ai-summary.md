# PRD: AI-саммари статей

Статус — Требования собраны.

## Проблема

Читателю нужно быстро понять основные тезисы сохранённой статьи, когда нет времени читать её целиком. Саммари даёт три кратких тезиса прямо в библиотеке и в начале статьи.

Сейчас Linkbook публикует карточку со статусом `ready` вместе с архивом статьи. Карточка показывает статус, заголовок и адрес, а читалка — заголовок и сохранённый текст. Существующее действие «Повторить» запускает обработку ссылки для статей в состояниях `failed` или `unavailable`. [Контракт библиотеки](../../backend/api/library.md), [карточка](../../web/src/_pages/library/ui/saved-link-card.tsx), [читалка](../../web/src/_pages/reader/ui/reader-page.tsx).

## Пользователи и сценарии

- Читатель сохраняет ссылку в личную библиотеку. Как только статья успешно обработана, её можно читать. Сервис сразу запускает генерацию саммари и показывает её состояние в карточке и читалке.
- Читатель просматривает библиотеку или открывает статью с готовым саммари и знакомится с её основными тезисами.
- Если генерация завершилась ошибкой, читатель может открыть статью и позже запустить повторную генерацию из её карточки.
- Администратор сервиса задаёт через переменные окружения общий для всех пользователей адрес OpenAI-совместимого API, ключ и модель. Настройки позволяют подключить совместимый API выбранного провайдера.

## Не делаем

- Догенерация саммари для статей, успешно обработанных до запуска фичи.
- Персональные настройки подключения в профиле. Администратор конфигурирует подключение централизованно через переменные окружения.

## Критерии готовности

- [ ] При корректных настройках и успешной обработке статьи после запуска фичи сервис инициирует генерацию без действий читателя. Вызов уходит на настроенный OpenAI-совместимый адрес с заданным ключом и моделью.
- [ ] При ошибке обработки статьи или отсутствии доступного текста вызова API для генерации саммари нет.
- [ ] Пока ответ API ожидается, карточка и читалка показывают индикатор генерации. Читатель может открыть статью и прочитать её текст.
- [ ] После успешной генерации карточка и начало читалки показывают один и тот же список из трёх основных тезисов, по одному короткому предложению на пункт. Тезисы написаны на языке статьи, в том числе когда он отличается от языка интерфейса.
- [ ] При ошибке генерации с корректными настройками статья по-прежнему открывается, а в карточке доступно действие «Повторить генерацию».
- [ ] Нажатие «Повторить генерацию» запускает новую попытку для сохранённой статьи. Во время попытки индикатор виден в обоих местах. При успехе там появляются тезисы, при повторной ошибке действие снова доступно в карточке.
- [ ] Статья, успешно обработанная до запуска фичи, остаётся доступной без саммари и без действия для его генерации.
- [ ] При отсутствующих или некорректных настройках подключения статья открывается, а в карточке и читалке отсутствуют блок саммари, индикатор и действие повтора.
- [ ] Администратор может использовать другой совместимый API, задав его адрес, ключ и модель через переменные окружения.
