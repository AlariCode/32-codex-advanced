# PRD: Сохранение ссылки и чтение очищенной статьи

Статус: Черновик — основные требования собраны; оставшиеся продуктовые и технические вопросы перечислены ниже.

## Проблема

Пользователь хочет вставить ссылку на статью из интернета, через несколько секунд увидеть в личном списке карточку с заголовком и прочитать статью внутри Linkbook без меню, рекламы и постороннего содержимого страницы.

Текущий контекст проекта, а не новые требования:

- Регистрация и вход реализованы. Вход сохраняет сессию в БД с истечением через 24 часа: [логика входа](../../backend/api/internal/user/login.go), [миграция сессий](../../backend/migrations/002-create-user-sessions.sql).
- API содержит маршруты регистрации, входа и проверки состояния; маршрутов библиотеки пока нет: [router.go](../../backend/api/internal/httpapi/router.go).
- Главная страница сообщает, что библиотека скоро появится: [page.tsx](../../web/src/app/page.tsx).
- Worker пока только ожидает завершения процесса: [worker.go](../../backend/worker/internal/worker/worker.go).
- Есть нормализация URL и тесты: [normalize.go](../../backend/api/internal/link/normalize.go), [normalize_test.go](../../backend/api/internal/link/normalize_test.go). Она принимает абсолютные HTTP(S)-адреса, удаляет внешние пробелы, фрагмент и параметры `utm_*`, приводит адрес к HTTPS и хост к нижнему регистру, сохраняя путь и остальные параметры. Существующие правила сами по себе не определяют все требования к новой форме добавления.

Подтверждённый результат фичи: личная библиотека со всем простым циклом добавления, обработки, чтения и удаления. Пользователь получает сохранённую версию статьи с базовым форматированием и изображениями, которая остаётся доступной при изменении или исчезновении оригинала.

## Пользователи и сценарии

Пользователь — вошедший в Linkbook владелец личной библиотеки. Он видит только свои карточки.

1. **Первая ссылка.** В пустой библиотеке пользователь видит предложение сохранить первую ссылку. Вставляет адрес и нажимает «Сохранить»; предварительная карточка появляется сразу.
2. **Добавление и ожидание.** Пользователь сохраняет ссылку и продолжает пользоваться списком. Карточка показывает URL и состояние обработки; после успеха автоматически получает заголовок и возможность открыть статью.
3. **Чтение.** Пользователь открывает готовую карточку и читает сохранённую статью с изображениями. Из читалки может вернуться в список или открыть оригинал.
4. **Возвращение позже.** После подтверждённого сохранения закрытие страницы не прерывает обработку. При возвращении пользователь видит текущее состояние или результат.
5. **Ошибка.** Пользователь видит проблему в карточке и доступное действие: исправить адрес, повторить сохранение или обработку, открыть оригинал либо удалить карточку — в зависимости от этапа ошибки.
6. **Страница без доступного текста статьи.** Пользователь сохраняет такую страницу как ссылку без читалки и впоследствии открывает оригинал.
7. **Повторное добавление.** Если ссылка уже есть у пользователя, он получает сообщение «Ссылка уже сохранена» и переходит к существующей карточке без создания дубликата. Для сопоставления учитывается существующая нормализация URL.
8. **Удаление.** Пользователь может удалить любую карточку из своей библиотеки.

## Критерии готовности

- [ ] Вошедший пользователь видит только свои карточки; новые карточки располагаются сверху. В пустом списке есть предложение сохранить первую ссылку.
- [ ] После нажатия «Сохранить» предварительная карточка с URL появляется сразу, до подтверждения сохранения.
- [ ] При некорректном URL ошибка отображается в предварительной карточке и пользователь может исправить адрес; при ошибке сохранения может повторить отправку из карточки.
- [ ] После сохранения ссылка отображается со статусом «Обрабатываем», при этом пользователь может продолжать пользоваться списком.
- [ ] При успешной обработке карточка автоматически получает заголовок, а пользователь может открыть очищенную статью без ручного обновления списка.
- [ ] В читалке сохраняются базовое форматирование, ссылки и изображения статьи; меню, реклама и постороннее содержимое страницы отсутствуют. Набор страниц для проверки качества ещё требуется определить.
- [ ] После изменения или исчезновения оригинала ранее успешно сохранённая версия текста и изображений остаётся доступной для чтения.
- [ ] Если обработка длится более 30 секунд, карточка показывает «Обработка занимает больше времени» и продолжает автоматически обновляться; превышение этого срока само по себе не считается ошибкой.
- [ ] Закрытие страницы после сохранения не прерывает обработку; при возвращении видно её текущее состояние или результат.
- [ ] При ошибке обработки карточка остаётся с URL, понятной причиной и действиями «Повторить», «Открыть оригинал», «Удалить». Повторная попытка отображает обработку и её новый результат в этой карточке.
- [ ] Главная страница, PDF, видео и страница с требованием входа или оплаты сохраняются как ссылки без читалки: есть заголовок, если получен, сообщение «Текст статьи недоступен», открытие оригинала и удаление.
- [ ] Повторное добавление ссылки, уже имеющейся у пользователя после нормализации, не создаёт дубликат: показывается сообщение и существующая карточка.
- [ ] Из читалки можно вернуться в список и открыть оригинал; любую карточку можно удалить из своей библиотеки.
