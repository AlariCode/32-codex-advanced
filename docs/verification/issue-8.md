## Принятые решения

- Введена версия 2; исторические документы v1 не мигрируют и читаются прежним способом. Это минимальный путь совместимости без сырого HTML.
- Readeck меняет h1 в h2, теряет короткие таблицы и details/summary. Перед выбором статьи эти узлы заменяются текстовыми placeholders с непредсказуемыми маркерами и исходными class/id для отбора Readeck. Восстанавливаются только фрагменты, оставшиеся внутри выбранной статьи, на прежнем месте и один раз. Не выбранные фрагменты не добавляются из всего исходника; потеря отмечается предупреждением. Вложенные структуры исходного фрагмента проходят тот же allowlist.
- Сохраняются только известные semantic kinds, children, текст, язык кода, heading level, ordered и разрешённый href. Произвольные props/styles не передаются. Rowspan/colspan/start не переносятся, их потеря явно помечается предупреждением.
- Браузерное восстановление подчёркивает границу безопасности: React получает только явно перечисленные теги и props, без HTML fallback или spread атрибутов. CodeBlock продолжает генерировать собственную безопасную подсветку из текста.
- OpenAPI JSON/YAML/Go и встроенная схема HTML синхронизированы локально для новых children/href; генератор с загрузками не запускался при запрете сети. `make openapi` и сборку выполнит внешний скрипт.
