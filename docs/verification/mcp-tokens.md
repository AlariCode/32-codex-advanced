## Покрытие

Go integration проверяет случайные независимые токены, точный SHA-256 в базе,
owner-scoped список и отзыв, отсутствие секретов/хэшей в списке, защиту Origin,
401 без сессии при управлении токенами, 401 без Bearer или с неверным/отозванным
Bearer, несовместимость website cookie и MCP-токенов, владельца созданной ссылки,
изоляцию библиотек и работу другого активного токена после отзыва первого.
Существующие MCP-тесты проверяют инструменты, ресурсы и запрет Origin.

UI-тесты проверяют однократный показ/копирование, отсутствие browser storage,
обновление страницы, отмену/подтверждение отзыва, фокус клавиатуры, ошибки и повтор,
401 и очистку приватного содержимого при смене аккаунта.

Сквозной тест регистрирует пользователя, переходит из библиотеки в профиль,
создаёт токен, сохраняет ссылку через MCP и находит её в библиотеке владельца.
После reload остаются только метаданные; после отзыва через UI следующий MCP-запрос
получает 401. Также проверены запросы без токена и с неверным токеном.
